Wigner 3-j symbols.

wigner3j
Syntax
v = wigner3j(j1,j2,j3,m1,m2,m3)
v = wigner3j(jm1,jm2,jm3)
v = wigner3j(jjj,mmm)
v = wigner3j(jjjmmm)
Description

wigner3j returns the value of the 3-j symbol

The six parameters can be specified separately or in groups. In the three-argument form, wigner3j takes jm1 = [j1 m1], jm2 = [j2 m2] and jm3 = [j3 m3]. If two arguments are given, it takes jjj = [j1 j2 j3] and mmm = [m1 m2 m3]. If one argument is given, it takes the 2x3 array jjjmmm = [j1 j2 j3; m1 m2 m3].

If the parameters violate one of the selection rules (m1+m2+m3 = 0, triangle condition for j1, j2, j3, |m|≤j for each column), wigner3j returns 0.

wigner3j returns accurate values for j values as large as several thousand.

Examples
wigner3j([1 1 0; 0 0 0])

ans =
   -0.57735

wigner3j([4 2 4; -2 -1 3])

ans =
    0.19462
Algorithm

If any of the three j values is less than or equal to 2, wigner3j uses explicit expressions. If all three m values are zero, it uses a dedicated product formula. In all other cases, it uses the Schulten-Gordon algorithm, a three-term recursion relation in j1: it computes the 3-j symbols for all allowed values of j1 at once, with forward recursion from the smallest j1 and backward recursion from the largest j1, and fixes their overall scale and sign via the normalization relation. This is numerically stable and accurate to about machine precision in double-precision arithmetic, even for large j values.

wigner3j implements expressions from

  • A. R. Edmonds, Angular Momentum in Quantum Mechanics, Princeton University Press, 1957
  • Robert E. Tuzun, Paul Burkhardt, Don Secrest, Computer Physics Communications 112, 112-148 (1998), doi:10.1016/S0010-4655(98)00065-4
  • Klaus Schulten, Roy G. Gordon, J. Math. Phys. 16, 1961-1970 (1975), doi:10.1063/1.522426
