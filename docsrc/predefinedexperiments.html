Predefined experiments

saffron and spidyan have predefined pulse experiments, selected via Exp.Sequence. For each, this page lists its parameters and the equivalent user-defined sequence, which you can modify further.

All pulses are along x, and the detection phase is chosen so that the echo is real and positive. With the fast method of saffron, pulses are ideal. With the thyme method and spidyan, they are rectangular pulses at Exp.mwFreq, 16 ns long for π/2 and 32 ns for π; these support all experiments except 'MimsENDOR'. The equivalent sequences give the same signal, but their time axis starts at zero.

2pESEEM

π/2 – τ – π – τ – echo, with τ incremented. 

Exp.Sequence = '2pESEEM';
Exp.tau = 0.1;  % initial tau, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.dt
Increment of τ, in µs.
Exp.tau
Initial τ, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined sequence: 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p180 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d1,d2' 0.01};
Exp.DetPhase = -pi/2;
3pESEEM

π/2 – τ – π/2 – T – π/2 – τ – echo, with T incremented. 

Exp.Sequence = '3pESEEM';
Exp.tau = 0.1;  % tau, µs
Exp.T = 0.08;   % initial T, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of T, in µs.
Exp.T
Initial T, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined sequence: 

p90.Flip = pi/2;
Exp.Sequence = {p90 0.1 p90 0.08 p90 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d2' 0.01};
Exp.DetPhase = -pi/2;
4pESEEM

π/2 – τ – π/2 – T – π – T – π/2 – τ – echo, with both T incremented. 

Exp.Sequence = '4pESEEM';
Exp.tau = 0.1;  % tau, µs
Exp.T = 0.08;   % initial T, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of T, in µs.
Exp.T
Initial T, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined sequence. The filter removes the echo refocused by the π pulse, which the predefined experiment does not include. 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p90 0.08 p180 0.08 p90 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d2,d3' 0.01};
Exp.Filter = '+00-';
Exp.DetPhase = pi/2;
HYSCORE

π/2 – τ – π/2 – t1 – π – t2 – π/2 – τ – echo, with t1 and t2 incremented independently. 

Exp.Sequence = 'HYSCORE';
Exp.tau = 0.1;  % tau, µs
Exp.t1 = 0.08;  % initial t1, µs
Exp.t2 = 0.08;  % initial t2, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of t1 and t2, in µs. Two values can be given, one per dimension.
Exp.t1, Exp.t2
Initial t1 and t2, in µs, default 0.
Exp.nPoints
Number of points along t1 and t2, e.g. [128 64]. A single value applies to both. Default [256 256] with fast, [128 128] with thyme and spidyan.

Equivalent user-defined sequence: 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p90 0.08 p180 0.08 p90 0.1};
Exp.nPoints = [256 256];
Exp.Dim1 = {'d2' 0.01};
Exp.Dim2 = {'d3' 0.01};
Exp.DetPhase = pi/2;
MimsENDOR

π/2 – τ – π/2 – T – π/2 – τ – echo, with an rf π pulse during T, swept over a frequency range. fast method only. There is no equivalent user-defined sequence, since these cannot contain rf pulses. 

Exp.Sequence = 'MimsENDOR';
Exp.tau = 0.1;  % tau, µs
Exp.Range = larmorfrq('1H',Exp.Field) + [-1 1]*10;  % rf range, MHz

Parameters:

Exp.tau
τ, in µs.
Exp.Range
Lower and upper limits of the rf range, in MHz, e.g. [0 30].
Exp.nPoints
Number of points, default 1001.
Exp.T
T, in µs, excluding the rf pulse. Default 0.
Exp.tprf
Length of the rf pulse, in µs, default 20. It sets the rf excitation bandwidth for Opt.EndorMethod 1 and 2.
Equivalent sequences for thyme and spidyan

Starting from the equivalent sequences above, add the pulse lengths and detect at the echo maximum. With rectangular pulses, the echo peaks slightly later than with ideal pulses, by 2/π times the length of the π/2 pulses. 

p90.tp = 0.016;   % µs
p180.tp = 0.032;  % µs
Exp.DetWindow = 2*p90.tp/pi;  % echo position, µs

Also add the phase cycles. They keep only the echo and remove all other signals, for systems with S = 1/2: 

sel = [0 1; pi/2 1i; pi -1; 3*pi/2 -1i];
odd = [0 1; pi -1];
even = [0 1; pi 1];
Exp.PhaseCycle = {sel};              % 2pESEEM
Exp.PhaseCycle = {sel [] odd};       % 3pESEEM
Exp.PhaseCycle = {sel [] even odd};  % 4pESEEM, HYSCORE

For '4pESEEM', the phase cycle replaces Exp.Filter, which works only with the fast method.

The predefined experiments use these phase cycles in the thyme method and in spidyan, so you cannot change Exp.PhaseCycle for them.
