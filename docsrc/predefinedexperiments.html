Predefined experiments

saffron has predefined pulse experiments, selected via Exp.Sequence. Each of them is a shortcut for a user-defined experiment: a pulse sequence with its incrementation scheme, coherence pathway selection and detection phase. For each, this page lists its parameters and the equivalent user-defined experiment, which you can modify further. saffron also returns the equivalent user-defined experiment in info.Exp: 

[x,y,info] = saffron(Sys,Exp);
ExpCustom = rmfield(info.Exp,'Macro');   % gives the same result as Exp

All microwave pulses are along x, and the detection phase is chosen so that the echo is real and positive. A single point is detected at the end of the sequence. The predefined experiments work with both simulation methods; saffron chooses the method as for any other experiment.

Predefined experiments are not available for spin systems with an electron spin S > 1/2, since their pulses are defined by flip angles, which have no unique meaning with several EPR transitions. For such systems, give the sequence explicitly, with the pulse strengths as Amplitude (see saffron). The info.Exp of an S = 1/2 simulation serves as a template.

Parameters common to all predefined experiments:

Exp.tp
Lengths of the microwave pulses, in µs: one value for all of them, or one value per microwave pulse. By default, the pulses are ideal (zero length). With finite lengths, the pulses are rectangular, and they select orientations and transitions according to Exp.mwFreq and the spin system. 'DaviesENDOR' requires finite pulses.
Exp.nPoints
Number of points. The defaults are given below.

The following fields cannot be used with predefined experiments, since the experiments set them themselves: Exp.Dim1, Exp.Dim2, Exp.Pathways, Exp.PhaseCycle, Exp.OnOff, Exp.DetPhase and Exp.rfFreq. To change them, start from the equivalent user-defined experiment.

2pESEEM

π/2 – τ – π – τ – echo, with τ incremented. 

Exp.Sequence = '2pESEEM';
Exp.tau = 0.1;  % initial tau, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.dt
Increment of τ, in µs.
Exp.tau
Initial τ, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined experiment: 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p180 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d1,d2' 0.01};
Exp.Pathways = '+-';
Exp.DetPhase = -pi/2;
3pESEEM

π/2 – τ – π/2 – T – π/2 – τ – echo, with T incremented. 

Exp.Sequence = '3pESEEM';
Exp.tau = 0.1;  % tau, µs
Exp.T = 0.08;   % initial T, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of T, in µs.
Exp.T
Initial T, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined experiment: 

p90.Flip = pi/2;
Exp.Sequence = {p90 0.1 p90 0.08 p90 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d2' 0.01};
Exp.Pathways = '+0-';
Exp.DetPhase = -pi/2;
4pESEEM

π/2 – τ – π/2 – T – π – T – π/2 – τ – echo, with both T incremented. 

Exp.Sequence = '4pESEEM';
Exp.tau = 0.1;  % tau, µs
Exp.T = 0.08;   % initial T, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of T, in µs.
Exp.T
Initial T, in µs, default 0.
Exp.nPoints
Number of points, default 512.

Equivalent user-defined experiment. The pathway selection keeps only the echo for which the electron spin is in a population state (coherence order 0) during both T periods. 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p90 0.08 p180 0.08 p90 0.1};
Exp.nPoints = 512;
Exp.Dim1 = {'d2,d3' 0.01};
Exp.Pathways = '+00-';
Exp.DetPhase = pi/2;
HYSCORE

π/2 – τ – π/2 – t1 – π – t2 – π/2 – τ – echo, with t1 and t2 incremented independently. 

Exp.Sequence = 'HYSCORE';
Exp.tau = 0.1;  % tau, µs
Exp.t1 = 0.08;  % initial t1, µs
Exp.t2 = 0.08;  % initial t2, µs
Exp.dt = 0.01;  % increment, µs

Parameters:

Exp.tau
τ, in µs.
Exp.dt
Increment of t1 and t2, in µs. Two values can be given, one per dimension.
Exp.t1, Exp.t2
Initial t1 and t2, in µs, default 0.
Exp.nPoints
Number of points along t1 and t2, e.g. [128 64]. A single value applies to both. Default [256 256].

Equivalent user-defined experiment: 

p90.Flip = pi/2;
p180.Flip = pi;
Exp.Sequence = {p90 0.1 p90 0.08 p180 0.08 p90 0.1};
Exp.nPoints = [256 256];
Exp.Dim1 = {'d2' 0.01};
Exp.Dim2 = {'d3' 0.01};
Exp.Pathways = '+00-';
Exp.DetPhase = pi/2;
MimsENDOR

π/2 – τ – π/2 – T – RF π – π/2 – τ – echo, with the RF frequency swept over a range. The signal is the ENDOR effect: the difference between the echo without and with the RF pulse. 

Exp.Sequence = 'MimsENDOR';
Exp.tau = 0.1;  % tau, µs
Exp.Range = larmorfrq('1H',Exp.Field) + [-1 1]*10;  % RF range, MHz

Parameters:

Exp.tau
τ, in µs.
Exp.Range
Lower and upper limits of the RF range, in MHz, e.g. [0 30].
Exp.nPoints
Number of points, default 1001.
Exp.T
Delay between the second microwave pulse and the RF pulse, in µs, default 0.
Exp.tprf
Length of the RF pulse, in µs, default 20. It sets the RF excitation bandwidth.

Equivalent user-defined experiment, for Exp.Range = [10 20] and 21 points. The RF pulse is switched on and off (Exp.OnOff), and the signal is the difference. Since the RF pulse reduces the stimulated echo, the detection phase makes this ENDOR effect positive. 

p90.Flip = pi/2;
RF.Channel = 'rf';
RF.Flip = pi;
RF.tp = 20;
Exp.Sequence = {p90 0.1 p90 0 RF 0 p90 0.1};
Exp.rfFreq = 10;
Exp.nPoints = 21;
Exp.Dim1 = {'rfFreq' 0.5};
Exp.Pathways = '+00-';
Exp.OnOff = 3;
Exp.DetPhase = +pi/2;
DaviesENDOR

π – T – RF π – π/2 – τ – π – τ – echo, with the RF frequency swept over a range. The microwave pulses must be selective, so their lengths must be given in Exp.tp. The signal is the ENDOR effect: the difference between the echo with and without the RF pulse. 

Exp.Sequence = 'DaviesENDOR';
Exp.tau = 0.3;              % tau, µs
Exp.tp = [0.2 0.1 0.2];     % lengths of the inversion, pi/2 and pi pulses, µs
Exp.Range = larmorfrq('1H',Exp.Field) + [-1 1]*10;  % RF range, MHz

Parameters:

Exp.tau
τ, in µs.
Exp.tp
Lengths of the three microwave pulses, in µs. Required.
Exp.Range
Lower and upper limits of the RF range, in MHz.
Exp.nPoints
Number of points, default 1001.
Exp.T
Delay between the inversion pulse and the RF pulse, in µs, default 0.
Exp.tprf
Length of the RF pulse, in µs, default 20.

Equivalent user-defined experiment, for Exp.Range = [10 20] and 21 points: 

pinv = struct('Flip',pi,'tp',0.2);
p90 = struct('Flip',pi/2,'tp',0.1);
p180 = struct('Flip',pi,'tp',0.2);
RF.Channel = 'rf';
RF.Flip = pi;
RF.tp = 20;
Exp.Sequence = {pinv 0 RF 0 p90 0.3 p180 0.3};
Exp.rfFreq = 10;
Exp.nPoints = 21;
Exp.Dim1 = {'rfFreq' 0.5};
Exp.Pathways = '00+-';
Exp.OnOff = 2;
Exp.DetPhase = -pi/2;
Finite pulses and the echo position

With rectangular pulses of finite length (Exp.tp), the echo peaks slightly later than with ideal pulses, by about 2/π times the length of the π/2 pulses. Since the predefined experiments detect at the end of the sequence, this can give a small signal phase for spins off resonance. To detect at the echo maximum, start from the equivalent user-defined experiment and set the detection point: 

ExpCustom = rmfield(info.Exp,'Macro');
ExpCustom.DetWindow = 2*Exp.tp(1)/pi;   % echo position, µs
