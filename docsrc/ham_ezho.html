ham_ezho
Syntax

Higher-order electron Zeeman Hamiltonian and its field-independent tensors. 

H = ham_ezho(Sys, B)
H = ham_ezho(Sys, B, idx)
H = ham_ezho(Sys, B, idx, 'sparse')
H = ham_ezho(Sys, B, idx, 'sparse', lB)
[G0, G1, G2, G3] = ham_ezho(Sys)
[G0,...] = ham_ezho(Sys, idx)
[G0,...] = ham_ezho(Sys, idx, 'sparse')
[GlB1,GlB2,...] = ham_ezho(Sys, idx, 'sparse', lB)
cG = ham_ezho(Sys)
cG = ham_ezho(Sys, [], idx, 'sparse', lB)
Description

ham_ezho calculates the matrix representing the multiple-order electron Zeeman interaction Hamiltonian (in units of MHz) for the spin system given in Sys.

Sys is a spin system structure. ham_ezho utilizes fields in Sys of the form Sys.Ham112, where the three digits indicate the order in the magnetic field lB (0 to 8), the rank of the spin operators lS (1 to 8), and the rank of the coupling l, respectively. For example, Sys.Ham334 indicates lB=3, lS=3 and l=4. lB+lS has to be even due to the time inversion symmetry of the Hamiltonian. The possible values for l run from |lB-lS| to lB+lS, but only even l are used. Fields with odd lB+lS or odd l are ignored, and lS=0 is not supported.

Each Ham field contains 2*l+1 real elements per electron spin, e.g. 9 for l=4, ordered as m=l,...,-l. For several electron spins, the field has one row per electron spin. A column vector with one value per electron spin is interpreted as the m=0 component. The unit of a field is MHz/mTlB. The results returned with field orders zero (lB=0) and one (lB=1) are equivalent to the zero-field interaction (obtainable also with ham_zf) and the standard electron Zeeman interaction (obtainable also with ham_ez).

B is a 3-element magnetic field vector (in mT). If given, the complete electron Zeeman Hamiltonian is returned. B is understood to be in the molecular frame, for example [0 0 340] indicates a field along the molecular z axis.

If B is omitted or empty, the function returns the field-independent tensors G0, G1, G2, G3, in units of MHz/mTn. Gn contains the coefficients of the terms of order n in the magnetic field, such that 

H = G0 + sum_i G1{i}*B(i) + sum_ij G2{i,j}*B(i)*B(j) + sum_ijk G3{i,j,k}*B(i)*B(j)*B(k)

where i, j, k = 1, 2, 3 correspond to the x, y, z components of B. G0 is a matrix, G1 is a 1x3 cell array, G2 is a 3x3 cell array, and G3 is a 3x3x3 cell array of matrices. G2 and G3 are symmetric in their indices. Gn is the n-th derivative of H divided by n!, e.g. G3{1,2,3} = 1/6*d^3H/(dBx dBy dBz). Tensors are available up to third order in B; fields of higher order are ignored.

idx is a number or array that indicates which electron spins should be included. For example, 1 indicates the first electron spin, and [2 3] indicates the second and third electron spins. If idx is omitted, all electron spins are included in the operators.

If 'sparse' is given as argument, results are returned in sparse format instead of full format.

If only terms of order lB in the magnetic field are required, a scalar or vector lB can be supplied as the last input. By default, all orders (0 to 8) are included in H, and all orders up to the highest one in Sys are returned as tensors. For tensors, lB can be 0 to 3.

With several outputs, the tensors for orders 0, 1, ... are returned, one per output; with lB given, the number of outputs must equal the number of elements in lB. With a single output, the tensors are returned in the cell array cG = {G0,G1,...}. To request specific spins or orders in this case, an empty array must be given in place of B, as in ham_ezho(Sys,[],idx,'sparse',lB).

Examples

To specify the common Zeeman term that is linear in the magnetic field (lB=1), use 

Sys.S = 5/2;
Sys.Ham110 = rand;       % MHz/mT; (lB,lS,l) = (1,1,0)
Sys.Ham112 = rand(1,5);  % MHz/mT; (lB,lS,l) = (1,1,2)

This is equivalent to using ham_ez.
