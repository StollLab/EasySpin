eulang

Get Euler angles from rotation matrix.

Syntax
angles = eulang(R)
[alpha,beta,gamma] = eulang(R)
Description

Given a rotation matrix R, the function eulang computes the Euler angles defining the same rotation and returns them separately or as a 3-element vector angles = [alpha, beta, gamma]. The angles are in radians.

The calculated Euler angles are such that if provided to erot, the input rotation matrix is recovered.

For details about Euler angles and rotation matrices, see the page on relative orientations.

The rotation matrix must be a real orthogonal 3x3 matrix with determinant +1. If the matrix is only slightly non-orthogonal, for example because its elements are rounded, eulang prints a message and replaces it by the closest orthogonal matrix (see below). If the matrix is far from orthogonal, or if its determinant is negative, eulang errors.

Since (α,β,γ) and (α+/-π,-β,γ+/-π) describe the same rotation, and since adding multiples of 2π to any angle does not change the rotation, there is more than one set of Euler angles that give the same rotation matrix. eulang returns the set with α and γ in the range [0,2π) and β in the range [0,π]. In the special cases β=0 and β=π, the rotation axes for α and γ coincide, and the two angles cannot be distinguished. In this case eulang sets γ to zero and describes the entire z rotation by α. For β=0, the returned α is α+γ, and for β=π, it is α-γ (both shifted into [0,2π)).

Algorithm

eulang first checks if the input matrix is orthogonal, using the deviation norm(R.'*R-eye(3)) of R.'*R from the identity matrix. If the deviation is above 10-2, eulang errors. If it is between 10-6 and 10-2, eulang replaces the matrix by its closest orthogonal neighbor using singular-value decomposition (SVD). Then, eulang determines the Euler angles analytically from the matrix elements.

For a matrix that is too far from orthogonal for eulang to accept, you can use SVD yourself to orthogonalize it: 

[U,~,V] = svd(R);  % calculate SVD, ignoring singular values
R = U*V.';         % construct orthogonal rotation matrix
Examples

Taking three arbitrary angles, we compute the rotation matrix 

ang = [34 72 -143]*pi/180;
R = erot(ang)

R =
    0.1319   -0.6369    0.7595
    0.6008   -0.5581   -0.5724
    0.7885    0.5318    0.3090

Now, feeding this rotation matrix into eulang, we get back the original angles. 

eulang(R)*180/pi

ans =
   34.0000   72.0000  217.0000

Since eulang returns γ in the range [0,2π), the original γ = -143° is returned as the equivalent 217° = -143° + 360°.

For β=0 and β=π, α and γ cannot be separated. eulang returns the combined z rotation in α and sets γ to zero: 

eulang(erot([30 0 20]*pi/180))*180/pi
eulang(erot([30 180 20]*pi/180))*180/pi

ans =
   50.0000         0         0
ans =
   10.0000  180.0000         0

For β=0, α = 30°+20° = 50°, and for β=π, α = 30°-20° = 10°.

If the elements of a rotation matrix are rounded, the matrix is slightly non-orthogonal. If the deviation is small, eulang orthogonalizes the matrix automatically. Here, the rotation matrix from above is rounded to three decimals: 

R_rounded = round(erot(ang)*1e3)/1e3;
eulang(R_rounded)*180/pi

eulang: Rotation matrix is not orthogonal, deviation is 0.00079683.
eulang: Orthogonalizing using singular-value decomposition (SVD).
ans =
   34.0235   71.9955  216.9808

The resulting angles are close to the original ones.

If the elements are rounded more coarsely, the deviation can be too large. Here is a rotation matrix with its elements rounded to one decimal: 

R_approx = [ 0.0   1.0  -0.1
            -0.8   0.0   0.6
             0.6   0.1   0.8];
norm(R_approx.'*R_approx - eye(3))

ans =
    0.0690

The deviation from orthogonality is too large, and eulang errors: 

eulang(R_approx)

Error using eulang
eulang: Rotation matrix is not orthogonal, deviation is 0.0689752.

To orthogonalize the matrix, use 

[U,~,V] = svd(R_approx);
R = U*V.'

R =
   -0.0298    0.9955   -0.0896
   -0.8013    0.0298    0.5975
    0.5975    0.0896    0.7969

eulang now works:

eulang(R)

ans =
    0.1489    0.6487    1.4219
