isotopologues

Generate list of isotopologues.

Syntax
isotopologues(NucList)
isotopologues(NucList,nEquiv)
isotopologues(NucList,nEquiv,Abundances)
isotopologues(NucList,nEquiv,Abundances,relThreshold)
isotopologues(Sys)
isotopologues(Sys,relThreshold)
out = isotopologues(...)
Description

This function computes all possible isotopologues of a given list of nuclei or elements, along with their abundances. It is a stand-alone version of the isotope-mixture handling that EasySpin's simulation functions perform internally for spin systems that contain natural-abundance or custom isotope mixtures (see the description of Sys.Nucs).

NucList is a character array with a comma-separated list of nuclei or elements, using the same syntax as Sys.Nucs, e.g. 'Cu' for a natural-abundance mixture of copper isotopes, '63Cu' for a single isotope, or '(12,13)C' for a custom isotope mixture.

nEquiv is a vector giving the number of equivalent nuclei for each entry in NucList (analogous to Sys.n). If omitted, it defaults to 1 for each nucleus.

Abundances is a cell array with one entry per nucleus, giving custom isotope abundances for any custom isotope mixtures in NucList (analogous to Sys.Abund). Use [] for natural-abundance mixtures and single isotopes.

relThreshold is the abundance threshold for isotopologues to be included in the output, relative to the abundance of the most abundant isotopologue. It must be between 0 and 1. Isotopologues less abundant than this are dropped. The default is 1e-4.

Instead of NucList, nEquiv and Abundances, a spin system structure Sys with fields Nucs, n and Abund can be given directly. If Sys also contains hyperfine and/or quadrupole fields (A, A_, Q, AFrame, QFrame), these are included in the output and rescaled for each isotope combination according to its nuclear g values and quadrupole moments.

If an output is requested, out is a structure array with one element per isotopologue, with the fields 

out(k).Nucs     comma-separated list of isotopes for this isotopologue
out(k).n        number of equivalent nuclei for each isotope
out(k).weight   absolute abundance (statistical weight) of this isotopologue

plus, if Sys was given, the corresponding rescaled A, A_, Q, AFrame and QFrame fields.

If no output is requested, the list of isotopologues is printed to the command window instead.

Examples

Copper has two naturally occurring isotopes, 63Cu and 65Cu. Without an output argument, the isotopologues and their abundances are printed: 

isotopologues('Cu')

Sys.Abund   Sys.Nucs Sys.n
  0.691700   63Cu     1
  0.308300   65Cu     1
2 of 2 isotopologues with abundance above threshold (1.00e-04)

With two elements, all combinations of isotopes are generated: 

isotopologues('Cu,N')

Sys.Abund   Sys.Nucs    Sys.n
  0.689155   63Cu,14N     1  1
  0.002545   63Cu,15N     1  1
  0.307165   65Cu,14N     1  1
  0.001135   65Cu,15N     1  1
4 of 4 isotopologues with abundance above threshold (1.00e-04)

With an output argument, the list is returned as a structure array instead of being printed: 

out = isotopologues('Cu,N');
out(1)

ans =
  struct with fields:

      Nucs: '63Cu,14N'
         n: [1 1]
    weight: 0.6892

Two equivalent copper nuclei give three isotopologues, since 63Cu/65Cu and 65Cu/63Cu are indistinguishable: 

isotopologues('Cu',2)

Sys.Abund   Sys.Nucs     Sys.n
  0.478449   63Cu          2
  0.426502   63Cu,65Cu     1  1
  0.095049   65Cu          2
3 of 3 isotopologues with abundance above threshold (1.00e-04)
