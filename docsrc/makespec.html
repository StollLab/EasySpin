makespec

Construct spectrum from peak positions and amplitudes.

Syntax
spec = makespec(Range,nPoints,Pos)
spec = makespec(Range,nPoints,Pos,Amp)
spec = makespec(Range,nPoints,Pos,Amp,Method)
[x,spec] = makespec(...)
[x,spec,nOut] = makespec(...)
Description

makespec collects the peaks with positions listed in Pos and amplitudes listed in Amp into a spectral vector spec. The 2-element array Range = [minX maxX] specifies the range of the abscissa, and nPoints gives the number of points. If requested, the abscissa is returned in x.

If Amp is not given or empty, all amplitudes are set to 1. If Amp is a single number, it is used for all peaks.

Method determines how each peak is assigned to the points of the abscissa x:

  • 'round' (default): The peak goes to the nearest point.
  • 'floor': The peak goes to the nearest point at or below the peak position.
  • 'split': The peak amplitude is split between the two neighboring points. The closer point gets the larger share. This keeps the total amplitude and the average position of the peaks.

Peaks that fall outside the specified range are neglected, and makespec issues a warning. If the third output nOut is requested, there is no warning, and nOut = [nBelow nAbove] gives the number of peaks below and above the range. Peaks with position NaN are ignored.

Examples

A simple demonstration bins a number of peaks with random positions and amplitudes into a spectral vector. 

N = 20;
pos = rand(1,N);
amp = rand(1,N);
[x,s] = makespec([-0.2,0.7],2000,pos,amp);
plot(x,s)
