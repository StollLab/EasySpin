Simulating pulse EPR spectra

This user guide explains how to simulate pulse EPR experiments such as ESEEM, HYSCORE and ENDOR with EasySpin's function saffron.

saffron has a number of common experiments built in. You can also define your own experiment: a pulse sequence (the pulses and the delays between them) together with an incrementation scheme (which delays or pulse parameters change from one data point to the next).

saffron has two simulation methods. The fast subspace method handles one electron spin with S = 1/2 coupled to any number of nuclei, with ideal or rectangular pulses. The general full-space method handles everything else, e.g. shaped pulses, transient detection, several electron spins or a resonator. saffron chooses the method automatically. This part of the guide covers what both methods can do; part II covers the features of the full-space method.

Running the simulation

To simulate a pulse EPR experiment, use EasySpin's saffron function. Its usage conforms to the other simulation functions in EasySpin. You need to provide it with two input arguments. The first one collects information about the spin system, and the second one collects information about the pulse experiment. There is an optional third input argument that allows you to set some algorithmic parameters.

Here is a simple example upfront, before we dive into more detail. Let's take a simple spin system: an electron spin coupled to a proton with a relatively weak hyperfine coupling. 

Sys.g = 2;
Sys.Nucs = '1H';   % a proton
Sys.A = [2 3 6];   % MHz

For more details on spin systems and their parameters, look at the page on the spin Hamiltonian.

For the experiment, the minimum information you need to provide is the magnetic field and the type of experiment, including its settings. For example, for two-pulse ESEEM: 

Exp.Field = 350;            % mT
Exp.Sequence = '2pESEEM';
Exp.dt = 0.005;             % µs

With these inputs, you can call the simulation function. If you don't ask for outputs, then it will plot the result. Otherwise, you get the result stored in the outputs, and nothing is plotted. For two-pulse ESEEM, a 1D experiment, the first output is the time τ, and the second output is the echo amplitude. 

saffron(Sys,Exp);           % plots the results

[tau,V] = saffron(Sys,Exp);   % returns results in tau (µs) and V
plot(tau,real(V),tau,imag(V));  % plotting real and imaginary part separately

The echo is real and positive. For a powder, the signal is averaged over all orientations. Without nuclear modulation, the two-pulse echo has an amplitude of 1/2, and the stimulated and four-pulse echoes have 1/4.

Predefined experiments

The most important parameters for a pulse EPR simulation are the magnetic field and the pulse experiment. The magnetic field is given in Exp.Field, in units of millitesla (mT): 

Exp.Field = 350;   % mT

There are two ways to specify the pulse experiment. You can either use one of the predefined ones, or you can define it fully yourself. We will discuss user-defined experiments further down. To use a predefined experiment, give its name in Exp.Sequence: 

Exp.Sequence = '2pESEEM';
Exp.Sequence = '3pESEEM';
Exp.Sequence = '4pESEEM';
Exp.Sequence = 'HYSCORE';
Exp.Sequence = 'MimsENDOR';
Exp.Sequence = 'DaviesENDOR';

The page on predefined experiments lists all of them with their parameters. By default, all microwave pulses are ideal (infinitely short, infinite bandwidth). Each of the predefined experiments needs additional parameters. For the ESEEM and HYSCORE experiments, you need to provide the time increment in Exp.dt. Note that the units are microseconds, not nanoseconds. 

Exp.dt = 0.010;    % microseconds; equal to 10 ns

For the two-dimensional HYSCORE experiment, saffron uses Exp.dt for both dimensions, unless you give two values.

Next, you need to specify the additional parameters of the experiment you selected. For the ESEEM and HYSCORE experiments, these are the initial inter-pulse delays: 

% Two-pulse ESEEM
Exp.tau = 0.080;   % initial tau value, in µs (default 0)

% Three-pulse ESEEM, four-pulse ESEEM
Exp.tau = 0.120;   % fixed tau value, in µs
Exp.T = 0.100;     % initial T value, in µs

% HYSCORE
Exp.tau = 0.130;   % fixed tau value, in µs
Exp.t1 = 0.100;    % initial value of t1, in µs
Exp.t2 = 0.100;    % initial value of t2, in µs

For the ENDOR experiments, you must specify the RF range in Exp.Range, in units of MHz: 

Exp.Range = [2 20];     % RF range, MHz

Further, you can specify the number of points. This is done in Exp.nPoints. If you don't give it, EasySpin uses a default value. 

Exp.nPoints = 200;        % for 1D experiments
Exp.nPoints = [200 200];  % for 2D experiments with equal dimensions
Exp.nPoints = [200 100];  % for 2D experiments with unequal dimensions
Orientation selection

With ideal pulses, all spins are excited, and you get a full powder spectrum, no matter what microwave frequency you are using. However, in practice, microwave pulse excitation bandwidths do not exceed 100 MHz or so. As a consequence, only spins within a subset of orientations in a powder sample are excited. This is referred to as orientation selection. Often, the limited excitation bandwidth also results in selective excitation of certain EPR transitions. This is termed transition selection.

To include orientation selection, give the pulses a length, and give the microwave frequency and the g tensor, so that saffron can determine which orientations are on resonance. For predefined experiments, the pulse lengths are given in Exp.tp, in µs: one value for all microwave pulses, or one value per pulse. 

Sys.g = [2.00 2.01 2.02];
Exp.mwFreq = 9.8;              % GHz
Exp.Field = 348.4;             % mT
Exp.tp = [0.016 0.032];        % pulse lengths for 2pESEEM, µs

The pulses are then rectangular, with the flip angles of the experiment. If your field and microwave frequency are far from resonance with any EPR transition, you won't get any intensity.

Simulating finite pulses is exact, but slower than ideal pulses. A faster approximation is to treat the pulses as ideal, but to excite only orientations within an excitation window of width 1/tp around the microwave frequency: 

Opt.IdealPulses = true;   % ideal pulses with an excitation window

The width of the EPR line, which matters for which spins are excited, can be given in Sys.lwAnisoG (see broadenings).

User-defined experiments

saffron allows you to define your own experiment. For this, you need to provide full details about pulses, delays and incrementation. An experiment is specified in two parts: the pulse sequence and the incrementation scheme. Together, they fully specify the experiment.

To specify the pulse sequence, you need to provide details about each pulse and the delays between them. Each pulse needs a flip angle and, if you want to use pulses with a finite length, a duration. Each pulse is defined as a structure, and pulses and delays are then combined in Exp.Sequence. The flip angles go into the field Flip, in radians: 

% Create two ideal pulses:
p90.Flip = pi/2;
p180.Flip = pi;

% Two-pulse echo sequence with ideal pulses
tau = 0.1; % start value for tau
Exp.Sequence = {p90 tau p180 tau};  % 90° - tau - 180° - tau

For pulses with a finite length, give the length in the field tp, in units of microseconds: 

% Create two rectangular pulses:
p90real.Flip = pi/2;  % flip angle
p90real.tp = 0.01;    % length of pulse in microseconds

p180real.Flip = pi;   % flip angle
p180real.tp = 0.02;   % length of pulse in microseconds

% HYSCORE sequence with rectangular pulses
tau = 0.1; % length of first interpulse delay in microseconds
t1 = 0;    % start value for t1
t2 = 0;    % start value for t2

Exp.Sequence = {p90real tau p90real t1 p180real t2 p90real tau};   % 90° - tau - 90° - t1 - 180° - t2 - 90° - tau

Omitting tp or setting it to zero corresponds to a zero-length pulse with infinite excitation bandwidth and the flip angle given in Flip. Delays go from the end of one pulse to the start of the next. Pulses with a length select orientations in the same way as described above, if Exp.mwFreq and the g tensor are given.

saffron detects a single point at the end of the sequence. Therefore, end the sequence with the delay after which the echo forms: in the two examples above, the last τ puts the detection point on the echo. (Transients and other detection points are covered in part II.)

If you have pulses with different phases, specify the phases in the field Phase. Again, give it in radians. A pulse with phase 0 is along x. 

p90.Phase = pi/2;      % set phase to +y
p180real.Phase = pi;   % set phase to -x

This defines the pulse sequence. Next, we need to define the incrementation scheme. This includes specifying which delays are incremented or decremented, and along which dimension of the data. For this, use the field Exp.Dim1 for a one-dimensional experiment, or Exp.Dim1 and Exp.Dim2 for a two-dimensional experiment. Each entry first has a character array that identifies the delay you want to change, which is followed by the size of the increment for each step in microseconds. For delays, the character array has the form 'dx', where d stands for 'delay' and x is the index of the delay, e.g. 'd1' is the first delay in Exp.Sequence. Here are a few examples: 

% One-dimensional experiment:
Exp.Dim1 = {'d1' 0.01}; % increment the first delay by 10 ns each step

% Two-dimensional experiment:
Exp.Dim1 = {'d2' 0.01}; % increment 2nd delay by 10 ns along the 1st dimension
Exp.Dim2 = {'d3' 0.02}; % increment 3rd delay by 20 ns along the 2nd dimension

It is also possible to change two or more delays within one dimension: 

% Increment two delays equally:
Exp.Dim1 = {'d1,d2' 0.01}; % increment the 1st and 2nd delay by 10 ns

% Increment two delays with different steps:
Exp.Dim1 = {'d1' 0.01; 'd2' 0.03};

If you want to decrement a delay instead of incrementing it, use negative signs. For example, the following gives a one-dimensional incrementation scheme where the second delay is incremented and the third one is decremented at the same time. This gives an experiment of constant length. 

Exp.Dim1 = {'d2' 0.01; 'd3' -0.01};    % combination of increment and decrement

Keep in mind that the starting values (the first data points) are always the ones given in Exp.Sequence. Pulse parameters, such as flip angles, phases and lengths, can be changed along the indirect dimensions in the same way (see part II and the reference page).

The last thing that is missing is to tell saffron the number of data points along each indirect dimension. This is done with Exp.nPoints. For a two-dimensional experiment, the points of both dimensions must be specified: 

Exp.nPoints = 200;        % for 1D experiments
Exp.nPoints = [200 200];  % for 2D experiments with equal dimensions
Exp.nPoints = [200 100];  % for 2D experiments with unequal dimensions

A pulse sequence produces many signals at the same time: echoes and free induction decays from different coherence transfer pathways. To keep only the signal you are interested in, select the pathways with Exp.Pathways: one character per pulse, giving the electron coherence order after the pulse ('+', '-', '0'). The last one must be '-', the detected coherence. 

Exp.Pathways = '+-';    % two-pulse echo
Exp.Pathways = '+0-';   % stimulated echo

Alternatively, use a phase cycle (Exp.PhaseCycle), as in a spectrometer. Without either, all pathways contribute. See the reference page on saffron for details.

The phase of the detected echo depends on the pathway and on the pulse phases. With Exp.DetPhase (in radians), you set the phase of the detection, as with the reference phase of a spectrometer. The predefined experiments use -π/2 for the two-pulse and stimulated echoes, and +π/2 for four-pulse ESEEM and HYSCORE, which makes the echo real and positive with pulses along x.

With all this, the user-defined version of a three-pulse ESEEM experiment could look like this: 

% Spin system
Sys.S = 1/2;
Sys.Nucs = '1H';
Sys.A_ = [5 2];

% Experiment: pulse sequence ...
p90.Flip = pi/2; % by providing only a flip angle, pulses are ideal
tau = 0.4;

Exp.Field = 350;
Exp.Sequence = {p90 tau p90 0 p90 tau}; % three-pulse sequence, the
                                        % starting value for the 2nd delay is 0
Exp.Pathways = '+0-';                   % stimulated echo
Exp.DetPhase = -pi/2;                   % detection phase for a real, positive echo

% ... and incrementation scheme
Exp.nPoints = 512;      % 512 data points
Exp.Dim1 = {'d2' 0.1};  % increment 2nd delay by 100 ns

saffron(Sys,Exp);

A predefined experiment is a shortcut for such a user-defined experiment. saffron returns the user-defined experiment in its third output, info.Exp. You can start from it and modify it: 

Exp.Sequence = '3pESEEM'; Exp.tau = 0.4; Exp.dt = 0.1;
[~,~,info] = saffron(Sys,Exp);
ExpCustom = rmfield(info.Exp,'Macro');   % the equivalent user-defined experiment
Single crystals

By default, saffron simulates powder spectra. But just like all other EasySpin simulation functions, it can also simulate single crystals. A crystal is simulated if Exp.CrystalSymmetry (the space group of the crystal) or Exp.MolFrame (the orientation of the spin system in the crystal) is given. Exp.SampleFrame gives the orientation of the crystal in the spectrometer: 

Exp.CrystalSymmetry = 'P21/c';    % space group
Exp.SampleFrame = [0 -pi/2 0];    % crystal x axis parallel to the static field

Without CrystalSymmetry or MolFrame, the sample is a powder and SampleFrame is ignored. For a single spin system with its molecular frame along the lab frame, use Exp.MolFrame = [0 0 0]. For more details, see the pages on frames and crystal simulations.

Options

saffron has a range of settings that can be used to adjust the level of theory and other aspects of the simulation. These are provided in the third input argument to saffron, usually called Opt. One of the most often needed parameters is Opt.GridSize, which specifies the resolution of the orientational grid used for powder simulations. The higher the number in Opt.GridSize, the finer the grid. 

Opt.GridSize = 19;   % 5° increments
Opt.GridSize = 31;   % 3° increments (default)
Opt.GridSize = 46;   % 2° increments
Opt.GridSize = 91;   % 1° increments

For systems with very anisotropic tensors, especially for HYSCORE, it is often necessary to increase Opt.GridSize to get fully converged spectra.

Another setting concerns the "product rule". This rule states that ESEEM traces from a spin system with several nuclei can be computed as products of the ESEEM traces from single-nucleus subsystems. It holds for ideal pulses, and saffron only uses it with ideal pulses. By default, it is not used. To activate it, use 

Opt.ProductRule = true;    % use the product rule

For other settings, including settings for data processing and display, see the reference page on saffron.

Adding relaxation

To add relaxation, give longitudinal and transverse relaxation times (T1, T2), in µs, in Sys.T1 and Sys.T2. If either of the two fields is omitted or set to zero, it is ignored. To switch relaxation off without removing the times, use Opt.Relaxation = false.

The subspace method multiplies the simulated signal with exponential decays: with T2 over the time the electron spin is in a coherence (e.g. during the two inter-pulse delays τ), and with T1 over the time it is in a population state (e.g. T in three-pulse ESEEM, or t1 and t2 in HYSCORE). The decay is the same for all orientations and does not depend on the nuclear coherences, so the ESEEM modulations decay along with the echo. This is done for ESEEM and HYSCORE experiments, predefined or user-defined. For ENDOR, relaxation has no effect in the subspace method. To limit relaxation to some delays, give one entry of Opt.Relaxation per element of Exp.Sequence, e.g. Opt.Relaxation = [0 1 0 0 0 1] for relaxation only during the two τ delays of {p90 tau p90 T p90 tau}. Entries for pulses have no effect, since the subspace method has no relaxation during pulses.

The following example shows how to add decay to a two-pulse experiment: 

Exp.Sequence = '2pESEEM';
Exp.Field = 324.9;
Exp.dt = 0.010;

Sys.Nucs = '14N';
nuI = larmorfrq(Sys.Nucs,Exp.Field);
Sys.A = 2*nuI;
Sys.Q = [4*0.1*nuI, 0.6];
Sys.T1 = 4; % adds longitudinal relaxation
Sys.T2 = 2; % adds transverse relaxation (phase memory time)

Transition-selective relaxation times (matrices in Sys.T1, Sys.T2) and relaxation during selected elements of the sequence need the full-space method, which saffron then uses (see part II).

Which method is used

saffron uses the fast subspace method whenever it supports all features of your experiment, and the full-space method otherwise. Both give the same signals where both apply. The method used, and the reason, are returned in the third output: 

[x,y,info] = saffron(Sys,Exp);
info.Method          % 'subspace' or 'fullspace'
info.MethodReason    % why the full-space method was needed

You can also request a method with Opt.Method = 'subspace' or 'fullspace'. If the subspace method does not support the experiment, saffron gives an error that names the feature. The reference page has a table of what each method supports.
